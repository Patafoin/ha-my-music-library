# My Music Library — Roadmap

## v1.0 — Basic (current)
- [x] HA integration scaffold (config flow, manifest)
- [x] Auto-register Lovelace card resource
- [x] Responsive player card (mobile / tablet / desktop)
- [x] Now playing: art, title, artist, progress
- [x] Transport controls: play/pause/prev/next
- [x] Volume + mute
- [x] Shuffle + repeat
- [x] Device picker (MA players)
- [x] Basic search (tracks, artists, albums)
- [x] Favorites tab (browse MA library)

## v1.1 — Queue Management
- [ ] View and manage current queue
- [ ] Add to queue / play next
- [ ] Clear queue
- [ ] Drag-to-reorder queue items

## v1.2 — Deep Browse
- [ ] Artist detail page (bio, albums, top tracks)
- [ ] Album detail page (tracklist, year, genre)
- [ ] Playlist detail page (editable)
- [ ] Breadcrumb navigation

## v1.3 — UI Polish
- [ ] Theme customization (accent color, dark/light)
- [ ] Smooth transitions / animations
- [ ] Skeleton loaders
- [ ] Touch gestures (swipe to next track)
- [ ] Mini player when card is small

## v1.4 — Advanced Features
- [ ] Transfer playback between devices (keep position)
